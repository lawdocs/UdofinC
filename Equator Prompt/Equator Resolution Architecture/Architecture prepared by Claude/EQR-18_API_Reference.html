FAMILY F · VISUAL & REFERENCE

API Reference

Browsable reference for the Equator Resolution Platform API — companion to the OpenAPI 3.1 spec (EQR-18_OpenAPI.yaml).
Document EQR-18 · Version 1.0 · 8 July 2026 · Confidential — Internal · See EQR-06 (integration) & EQR-12 (schema)
Base URLs. https://api.equatorresolution.com/v1 (prod) · https://sandbox.api.equatorresolution.com/v1 (sandbox). Auth. Bearer JWT via OAuth2/OIDC on every request. Webhooks are signed, retried and idempotent.
Endpoints: Parties · Cases · Escalation · Documents · Hearings · Outcomes · Payments · Dispute Explorer · Schemas · Webhooks

Parties

POST /parties
Register an individual party (F1)
Body: PartyCreate
Responses: 201400
GET /parties/{id}
Get a party
Params: id (path)
Responses: 200404
POST /parties/{id}/kyc
Submit KYC (video-KYC/DigiLocker)
Params: id (path)
Body: KycSubmit
Responses: 202
POST /entities
Register an organisation (KYB, F2)
Body: EntityCreate
Responses: 201

Cases

GET /cases
List cases
Params: pillar (query) status (query) limit (query)
Responses: 200
POST /cases
File a case (master filing, F5)
Body: CaseCreate
Responses: 201400
GET /cases/{id}
Get a case
Params: id (path)
Responses: 200404
GET /cases/{id}/status
Get case status timeline (eCourts-style)
Params: id (path)
Responses: 200
POST /cases/{id}/responses
File a response/defence (F9)
Params: id (path)
Body: ResponseCreate
Responses: 201

Escalation

POST /escalations
Escalate a company ticket into a case (F22)
Body: EscalationCreate
Responses: 201409
GET /escalations/{id}
Get an escalation
Params: id (path)
Responses: 200

Documents

POST /cases/{id}/documents
Upload a document (hashed on write)
Params: id (path)
Body: (multipart)
Responses: 201
GET /documents/{id}
Get document metadata (with hash)
Params: id (path)
Responses: 200

Hearings

GET /cases/{id}/hearings
List hearings for a case
Params: id (path)
Responses: 200
POST /hearings/{id}/join
Get a hearing join token (liveness-gated)
Params: id (path)
Responses: 200

Outcomes

GET /cases/{id}/settlement
Get the mediated settlement (MSA)
Params: id (path)
Responses: 200
GET /cases/{id}/award
Get the arbitral award
Params: id (path)
Responses: 200
GET /cases/{id}/execution-bundle
Get the court-ready execution bundle (S.36/S.27)
Params: id (path)
Responses: 200

Payments

POST /invoices
Raise an invoice
Body: InvoiceCreate
Responses: 201
POST /payments
Initiate a payment (Razorpay/PayPal)
Body: PaymentCreate
Responses: 201
GET /payouts/{id}
Get a neutral payout
Params: id (path)
Responses: 200

Dispute Explorer

POST /explorer/sessions
Start a Dispute Explorer session (AI, advisory)
Body: ExplorerCreate
Responses: 201
GET /explorer/sessions/{id}
Get a Dispute Explorer session
Params: id (path)
Responses: 200

Webhooks

  • case.filed — A case was filed
  • neutral.appointed — A neutral was appointed
  • hearing.scheduled — A hearing was scheduled
  • award.signed — An award was signed & stamped
  • settlement.paid — Settlement funds released
  • case.closed — A case was closed
