## 2. New state machines — scenario tables

### 2.1 Brand-pack version (P23 §5.8)

| Scenario | Path | Expected |
|---|---|---|
| Happy | DRAFT → save (contrast auto-check passes) → CONTRAST_CHECKED → submit → IN_REVIEW → checker ≠ maker approves → PUBLISHED; CDN purge; `BrandPackPublished` | Hosts in the version are all verified; prior version SUPERSEDED but reachable |
| Failure | Save with a failing pair → stays DRAFT with `LDC-WEB-053` and suggested shade; submit with an unverified host → `LDC-WEB-054`, stays CONTRAST_CHECKED | No partial publish |
| Concurrency | Two makers edit the same pack; second save on a stale version → optimistic-lock 409; checker approving while maker edits → approval applies to the submitted snapshot only | Versions are immutable snapshots |
| Rollback | Rollback to v3 creates v6 = snapshot(v3), PUBLISHED, with reason; CDN purged; `BrandPackPublished` with `rolled_back_from` | Rollback is itself auditable and reversible |

### 2.2 User post (P23 §5.9; NN-64)

| Scenario | Path | Expected |
|---|---|---|
| Happy | DRAFT → SUBMITTED (terms version and declarations frozen) → IN_MODERATION → APPROVED → PUBLISHED with "Author's view" label → `BlogPostPublished` (author_type user) | Routable only when PUBLISHED |
| Failure | DECLINED with reasons; author notified; may WITHDRAW or resubmit as a new DRAFT; script/iframe stripped at save (`LDC-WEB-059`); ineligible author → `LDC-WEB-061` | Nothing publishes without a checker |
| Concurrency | Blog turned OFF while a post is IN_MODERATION → moderation continues; publish blocked with `LDC-WEB-062` until ON; complaint arrives during IN_MODERATION → flagged to the moderator | No orphaned routes |
| Rollback / takedown | PUBLISHED → UNDER_COMPLAINT (timers 24 h / 15 d; 3 h for synthetic media [VERIFY]) → TAKEN_DOWN or back to PUBLISHED; TAKEN_DOWN keeps the record for the Transparency Report; author appeal 7 days | Grievance Policy timelines honoured |
