# v1.1 research note — G2 client feedback and reverse engineering (25 Oct 2026)

Key data points gathered (all accessed 25 Oct 2026; full list Appendix Z §Z.10):

- Komrisk (Capterra): 4.0/5, 15 reviews (2019–2022); ease 3.9, service 4.7. Cons: mapping tedious, remapping on field change, manual deletion of repetitive tasks, factory-level usability, incident management weak, updates verbose, on-time task flagged non-compliant when approval after due date.
- LexComply (Capterra): 4.9, 10 reviews; US$100/month basic flat; cons: one-by-one deletion, too detailed, browser dependence.
- Ricago (Capterra India): 5.0, 4 reviews; cons: notifications; no international coverage (2021).
- TeamLease RegTech case study: 5 SMEs × 6 weeks; 100+ Acts; 10 departments; 4,500 compliances (700+ event-based); 95 users; 10 trainings; litigation module post go-live.
- MetricStream (Gartner PI): 3.9, 48 ratings; complex UX; IT dependence; Excel import difficulty (TrustRadius summary via Sprinto).
- ServiceNow IRM (rfp.wiki): Gartner 4.3 (163), Capterra 4.5 (361), G2 4.4 (22), Trustpilot 2.0 (17); learning curve, admin, TCO; operator ~US$100–300/month indicative (G-Cloud 14).
- Now Assist for IRM agentic workflows: issue action plan + remediation tasks; regulatory alert enrichment + recommendation; regulatory action-plan (compares past alerts); risk suggestion.
- OneTrust (Sprinto summary): G2 4.4 (250+), Capterra 4.3, Trustpilot 1.5; weeks of configuration; modular escalation; Vendr median ≈ US$10.5k/yr (278 transactions).
- Vanta: G2 4.6 (2,703); Capterra 4.2 (33); contract/refund disputes; alarm fatigue; price; AI agent capabilities (Dec 2025 blog). Data model: integrations → resources → tests → controls → frameworks; test statuses OK/NEEDS_ATTENTION/DEACTIVATED/IN_PROGRESS/INVALID/NOT_APPLICABLE; custom tests immutable.
- Drata: G2 4.7 (1,337); support 9.5; MCP (Jun 2025); VRM agent (Aug 2025).
- Secureframe Comply AI: evidence validation incl. 12-month date check; risk autofill with justification; questionnaire answers with stored sources; vendor Q&A with page citations (50 parallel); MCP/API; global disable.
- Hyperproof (SaaSworthy): 4.7 (223); cons: report customisation, no delete after bulk errors, per-file sharing flag, slow downloads.
- ZenGRC (Capterra): 4.4 (27); cons: reporting, CSV round-trip bulk edits, integrations.
- LogicGate (G2): 4.6 (191); 4-month implementation; ROI 14 months; AI agents 2026.
- Optro (formerly AuditBoard): rebrand Mar 2026; AI scoping memos and cross-audit summaries (Mar 2025); FairNow acquisition (fall 2025).
- Diligent Boards: Capterra 4.7 (342), G2 4.5 (497); cons: dated UI, navigation, slow uploads, notes disrupted on file replace; AuditAI + Smart Prep 360 (10 Mar 2026), claimed admin time −70%.
- PolicyTech (Capterra NZ): 4.2 (28); value 3.5; cons: workflow visibility, many hand-offs, one e-mail per notification.
- Workiva (G2): 4.5 (2,268); 4-month implementation.
- Riskonnect (rfp.wiki): G2 4.3 (172); "many tasks need multiple clicks"; pricing opacity.
- OnFinance: US$4.2 m (Sep 2025); NeoGPT/ComplianceOS; NSE, BSE, ICICI Bank, HDFC MF.

Limitations: Gartner/G2 pages often show only snippets; several sources are competitor blogs (Sprinto, 6clicks); Indian tools have little public review data.
