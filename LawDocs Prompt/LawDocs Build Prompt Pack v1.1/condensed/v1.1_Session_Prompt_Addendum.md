## 0. How to start every session (v1.1)

1. Make sure the repository holds the current pack: `docs/00-master-prompt.md` (v1.1), `docs/01-decision-log.md` (v1.1), `docs/phases/`, `docs/appendices/`, `docs/reference/authoring-conventions.md`, **`docs/ipb/` (IPB v1.0, all thirteen files and `00_README.md`)** and `docs/ecosystem/infrabyx-integration-spec.md` (**v1.2**, tagged).
2. **Standing line for every session prompt:** *"Read docs/ipb/00_README.md first, then the IPB files the phase names as binding, then the master prompt, the decision log and the phase file."*
3. **Standing line for every phase plan:** *"Add a section 'IPB conformance' to docs/phases/PXX-plan.md listing: ports used (no vendor SDK outside packages/connectors), settings keys registered incl. any `vidhi.*`/`brand.*`/`cms.*`/`mkt.*`/`fb.*`/`trust.*`/`sec.*` keys, help keys, export-map entries, flags for unverified features, and any IPB-DEV you believe is needed (do not create one; propose it)."*
4. Work on a `cc/<phase>-<slug>` branch; the PR template's IPB conformance checklist must be complete before merge (P23 FR-P23-03A).
5. Approve the plan before code; stop at the exit gate; hand over per master §0 step 5.
